# Plan 02-01: PDF and TXT Detectors

**Phase:** 2 — Detection Engine
**Wave:** 1
**Goal:** Add `detect_invisible_unicode()`, `scan_txt()`, and `scan_pdf()` to `app.py`. All three functions share a common finding dict schema consumed by Phase 3's Results UI.

## Objective

Implement the PDF and TXT detection functions directly in `app.py`. PyMuPDF (`fitz`) is imported at the top of the file alongside the existing imports. The `scan_file()` stub is NOT replaced yet — that happens in Plan 02-02 once all detectors exist.

## Context

- `app.py` already exists with the stub `scan_file()` at the end of the file
- PyMuPDF imports as `fitz`; already in `requirements.txt`
- All detection functions return a **result dict** with this exact schema:
  ```python
  {
      "status": "safe" | "threat" | "error",
      "filename": str,
      "findings": list[dict],   # see finding schema below
      "error": str | None,      # only present when status == "error"
  }
  ```
- Each finding dict:
  ```python
  {
      "method": str,    # "Tiny font" | "White text" | "Invisible Unicode"
      "text":   str,    # the exact suspicious text string
      "page":   int | None,  # page number (1-based) for PDFs, None otherwise
  }
  ```
- Phase 3 Results UI reads this schema — do not deviate

        """
        Scan text for invisible Unicode characters used in prompt injection.
        Returns a list of finding dicts (method, text, page=None).
        """
        findings = []
        for char, name in INVISIBLE_CHARS.items():
            count = text.count(char)
            if count > 0:
                idx = text.find(char)
                context = text[max(0, idx - 20) : idx + 20].replace(
                    char, f"[{name}]"
                )
                findings.append(
                    {
                        "method": "Invisible Unicode",
                        "text": f"{count}× {name} — ...{context}...",
                        "page": None,
                    }
                )
        return findings

                "filename": uploaded_file.name,

    ```python
    def scan_pdf(uploaded_file):
        """
        Scan a PDF for hidden text: tiny font (< 4pt) and white text (color 16777215).
        Also runs invisible Unicode scan on the full extracted text.
        Returns a result dict.
        """
        findings = []
        try:
            data = uploaded_file.read()
            doc = fitz.open(stream=data, filetype="pdf")
            for page_num, page in enumerate(doc, start=1):
                page_dict = page.get_text("dict")
                for block in page_dict.get("blocks", []):
                    if block.get("type") != 0:  # 0 = text block
                        continue
                    for line in block.get("lines", []):
                        for span in line.get("spans", []):
                            text = span.get("text", "").strip()
                            if not text:
                                continue
                            size = span.get("size", 999.0)
                            color = span.get("color", -1)
                            if size < 4.0:
                                findings.append(
                                    {
                                        "method": "Tiny font",
                                        "text": text,
                                        "page": page_num,
                                    }
                                )
                            if color == 16777215:  # 0xFFFFFF white
                                findings.append(
                                    {
                                        "method": "White text",
                                        "text": text,
                                        "page": page_num,
                                    }
                                )
            # Unicode scan on the full document text
            full_text = doc.get_text()
            findings.extend(detect_invisible_unicode(full_text))
            doc.close()
            return {
                "status": "threat" if findings else "safe",
                "filename": uploaded_file.name,
                "findings": findings,
            }
        except Exception as exc:
            return {
                "status": "error",
                "filename": uploaded_file.name,
                "findings": [],
                "error": str(exc),
            }
    ```
